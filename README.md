# Kirby Pop
Kirby Pop is an AR/VR mobile game for Android developed with Unity version 6000.0.26f1. In this game, players must tap on Kirbys that appear around them before they get too close. Each Kirby tapped disappears and awards points.

## Description
Kirby Pop is an immersive AR/VR mobile game developed in Unity for Android. In this project, I focused on creating an interactive augmented and virtual reality experience where players tap on Kirbys appearing around them before they get too close. The game combines spatial awareness with fast-paced, touch-based gameplay, allowing users to engage with virtual objects seamlessly in a real-world environment. This project showcases my ability to design intuitive AR/VR interactions and implement responsive gameplay mechanics for mobile platforms.

## How to play
### Main Menu
In the main menu, the player can see their highest score achieved so far.
There are also two buttons available:
* Start – begins a new game session.
* Quit – exits the game.
### In-game
During gameplay, the player sees their real environment through the device’s camera. Kirbys appear around the player in augmented reality, and the goal is to find and tap them before they get too close.
The game ends when a Kirby touches the player.
There are two types of kirbys:
* Basic Kirby – pops after being tapped once.
* Big Kirby – requires three taps to pop and features a health bar.
### Pause Menu
In the pause menu, the player can view their maximum score and access several options:
* Resume – continue the current game.
* Restart – start a new game.
* Quit – exit the game.
